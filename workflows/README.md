# Workflow Staging Area

This folder contains the sanitized n8n exports used in the portfolio repository.

## Navigation

- [Workflow index](INDEX.md)

## Folder layout

- `content` - trend and social content automation
- `video` - video generation and publishing flows
- `rag` - knowledge base and chatbot pipelines
- `ops` - inbox and inventory automations
- `assistants` - standalone assistant workflows

## Publishing rule

Before publishing, verify that all credentials are externalized and any hardcoded tokens are removed.
